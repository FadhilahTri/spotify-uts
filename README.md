## Deskripsi Singkat
Proyek ini adalah aplikasi web untuk memprediksi popularitas lagu di Spotify menggunakan model pembelajaran mesin. Aplikasi ini memungkinkan pengguna untuk memasukkan fitur-fitur audio dari suatu lagu dan mendapatkan prediksi tingkat popularitasnya.

## Algoritma yang Digunakan
* **Linear Regression**: Model regresi linier sederhana sebagai baseline.
* **Artificial Neural Network (ANN)**: Model jaringan saraf tiruan (Deep Learning) untuk menangkap pola non-linier pada data.
* **Algoritma Lainnya**: (Opsional: K-Means untuk clustering, Backpropagation, LSTM, dll. sesuai dengan model yang ada di folder models).

## Cara Instalasi dan Menjalankan Aplikasi

1. Clone repositori ini:
   ```bash
   git clone [URL_REPOSITORI_ANDA]
   cd spotify-uts
   ```

2. Buat virtual environment (opsional namun disarankan):
   ```bash
   python -m venv venv
   # Di Windows
   venv\Scripts\activate
   # Di Linux/Mac
   source venv/bin/activate
   ```

3. Instal dependensi:
   ```bash
   pip install -r requirements.txt
   ```

4. Jalankan aplikasi web:
   ```bash
   python app/app.py
   ```

5. Buka browser dan akses:
   `http://127.0.0.1:5000/`
